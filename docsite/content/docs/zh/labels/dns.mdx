---
title: DNS 标签
description: 用容器标签创建 Cloudflare DNS 记录。
---

一个标签就够了。下面会为 `app.example.com` 创建一条开启代理的 `A` 记录，指向本机的公网 IP：

```yaml
services:
  web:
    image: nginx:alpine
    labels:
      labelgate.dns.web.hostname: "app.example.com"
```

容器删除 30 分钟后（`sync.remove_delay`），这条记录会被删除。

## 标签 [#properties]

标签格式都是 `labelgate.dns.<name>.<property>`。`<name>` 由你自己定，参见[名字部分](/zh/docs/labels#service-names)。

| 属性 | 必填 | 默认值 | 示例 | 含义 |
|------|------|--------|------|------|
| `hostname` | 是 | - | `app.example.com` | 记录名。 |
| `type` | 否 | `A` | `CNAME` | `A`、`AAAA`、`CNAME`、`TXT`、`MX`、`SRV` 或 `CAA`。 |
| `target` | `A`/`AAAA` 否，其他类型是 | `auto` | `203.0.113.10` | 记录值。参见[目标值](#targets)。 |
| `proxied` | 否 | `true` | `false` | 是否开启代理（橙色云朵）。只有 `A`、`AAAA`、`CNAME` 能开启。 |
| `ttl` | 否 | 自动 | `300` | TTL 秒数，最大 `86400`。`0` 或 `1` 表示自动。开启代理时始终为自动。 |
| `cleanup` | 否 | `true` | `false` | 容器删除后是否删除记录。`false` 表示保留。 |
| `credential` | 否 | 自动 | `company` | 使用哪个 [API token](/zh/docs/configuration/reference#multi-credential-setup)。`default` 表示 `cloudflare.api_token`。 |
| `access` | 否 | - | `team` | 在主机名前加一道 [Access 策略](/zh/docs/labels/access)。 |
| `comment` | 否 | - | `blog` | 写进 Cloudflare 记录备注的附加文字。 |
| `priority` | 否 | `0` | `10` | 仅 `MX` 和 `SRV`。0-65535。 |
| `weight` | 否 | `0` | `5` | 仅 `SRV`。0-65535。 |
| `port` | 否 | `0` | `5222` | 仅 `SRV`。0-65535。 |
| `flags` | 否 | `0` | `128` | 仅 `CAA`。0-255。 |
| `tag` | 否 | `issue` | `issuewild` | 仅 `CAA`。`issue`、`issuewild` 或 `iodef`。 |

## 目标值 [#targets]

`A` 和 `AAAA` 记录：

| `target` | 结果 |
|----------|------|
| `auto`（默认） | 本机公网 IP：`A` 用 IPv4，`AAAA` 用 IPv6。[agent](/zh/docs/examples/multi-host) 上的容器使用 agent 主机的公网 IP。 |
| `container` | 容器自己的 IP 地址。 |
| IP 地址 | 直接使用该地址，如 `A` 用 `203.0.113.10`，`AAAA` 用 `2001:db8::10`。 |

其他类型必须填写 `target`：

- `CNAME`、`MX`、`SRV`：填主机名，如 `mail.example.com`。
- `TXT`、`CAA`：填记录内容，原样写入。

如果 `auto` 或 `container` 找不到地址（比如没有公网 IPv6），记录会显示错误，Labelgate 每次同步都会重试。

## 常用示例 [#examples]

### 固定 IP，仅 DNS（灰色云朵）

```yaml
labels:
  labelgate.dns.web.hostname: "app.example.com"
  labelgate.dns.web.target: "203.0.113.10"
  labelgate.dns.web.proxied: "false"
```

### 一个容器创建多条记录

```yaml
labels:
  labelgate.dns.root.hostname: "example.com"
  labelgate.dns.www.hostname: "www.example.com"
  labelgate.dns.www.type: "CNAME"
  labelgate.dns.www.target: "example.com"
```

### 邮件：MX 和 SPF

```yaml
labels:
  labelgate.dns.mx.hostname: "example.com"
  labelgate.dns.mx.type: "MX"
  labelgate.dns.mx.target: "mail.example.com"
  labelgate.dns.mx.priority: "10"
  labelgate.dns.spf.hostname: "example.com"
  labelgate.dns.spf.type: "TXT"
  labelgate.dns.spf.target: "v=spf1 mx ~all"
```

`priority` 默认为 `0`，有需要时请明确设置。

### SRV

```yaml
labels:
  labelgate.dns.xmpp.hostname: "_xmpp-client._tcp.example.com"
  labelgate.dns.xmpp.type: "SRV"
  labelgate.dns.xmpp.target: "xmpp.example.com"
  labelgate.dns.xmpp.priority: "10"
  labelgate.dns.xmpp.weight: "5"
  labelgate.dns.xmpp.port: "5222"
```

### CAA

```yaml
labels:
  labelgate.dns.caa.hostname: "example.com"
  labelgate.dns.caa.type: "CAA"
  labelgate.dns.caa.target: "letsencrypt.org"
```

### 容器删除后保留记录

```yaml
labels:
  labelgate.dns.web.hostname: "app.example.com"
  labelgate.dns.web.cleanup: "false"
```

### 容器级默认值 [#per-container-defaults]

`labelgate.dns.default.<property>` 为同一容器里的所有 DNS 名字设置默认值。可用的属性：`type`、`target`、`proxied`、`ttl`、`credential`、`cleanup`。

```yaml
labels:
  labelgate.dns.default.proxied: "false"
  labelgate.dns.a.hostname: "a.example.com"
  labelgate.dns.b.hostname: "b.example.com"
```

## 注意事项

- Labelgate 只修改自己创建的记录。它在记录备注开头写上 `labelgate:<id>` 作为标记，你的 `comment` 跟在后面。
- 已存在的同名同类型记录永远不会被接管，会报 `conflict: existing record not owned by labelgate`。参见[所有权与冲突](/zh/docs/ownership)。
- 已经被 [Tunnel 标签](/zh/docs/labels/tunnel)使用的主机名，不要再加 DNS 标签。Tunnel 会自己创建记录。
