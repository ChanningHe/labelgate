给容器加上标签，Labelgate 就会在 Cloudflare 上创建对应的 DNS 记录、Tunnel 路由和 Access 策略。容器删除后，这些资源也会被清理。

```yaml
services:
  whoami:
    image: traefik/whoami
    labels:
      # 通过 tunnel 把 http://whoami:80 发布到 https://app.example.com
      labelgate.tunnel.web.hostname: "app.example.com"
      labelgate.tunnel.web.service: "http://whoami:80"
```

只读取正在运行的容器。如果设置了 `docker.filter_label`，只读取带有该标签的容器。

## 标签格式 [#format]

```
labelgate.<type>.<name>.<property>: "<value>"
```

| 部分 | 含义 | 示例 |
|------|------|------|
| `labelgate` | 前缀。可用 `label_prefix`（`LABELGATE_LABEL_PREFIX`）修改。 | `labelgate` |
| `<type>` | 要创建什么：`dns`、`tunnel` 或 `access`。 | `tunnel` |
| `<name>` | 你自己起的名字。名字相同的标签属于同一组。 | `web` |
| `<property>` | 具体设置项。每种类型有各自的列表。 | `hostname` |

## 名字部分 [#service-names]

名字用来把标签分组，一组对应一条记录或一条路由。名字随便起，只会出现在 Dashboard 和日志里。

同一个容器上要配置多条记录或路由时，给每条起不同的名字：

```yaml
labels:
  labelgate.tunnel.web.hostname: "www.example.com"
  labelgate.tunnel.web.service: "http://app:80"
  labelgate.tunnel.api.hostname: "api.example.com"
  labelgate.tunnel.api.service: "http://app:3000"
```

名字规则：

- 只能用小写字母、数字和 `-`，不能以 `-` 开头或结尾。
- 不能和属性名相同：`hostname`、`service`、`type`、`target`、`proxied`、`ttl`、`cleanup`、`credential`、`tunnel`、`path`、`origin`、`access`、`priority`、`weight`、`port`、`flags`、`tag`、`comment`。
- `default` 是特殊名字。`labelgate.dns.default.*` 和 `labelgate.tunnel.default.*` 为同一容器里其他名字设置默认值，参见 [DNS](/zh/docs/labels/dns#per-container-defaults) 和 [Tunnel](/zh/docs/labels/tunnel#per-container-defaults)。

## 主机名 [#hostnames]

- 不区分大小写，末尾的点会被忽略：`App.Example.com.` 就是 `app.example.com`。
- 允许开头使用通配符：`*.example.com`。

### 一个主机名只有一个所有者 [#dns-and-tunnel-on-the-same-hostname]

- Tunnel 路由会自己创建 DNS 记录。不要再为同一个主机名加 `dns` 标签，后加的一方会报冲突。
- 如果两个名字（无论在同一容器还是不同容器）声明了同一主机名和同一记录类型，先拿到的一方保留，另一方报冲突。
- 同一主机名上可以有多条 `MX`、`TXT`、`SRV` 或 `CAA` 记录。
- Labelgate 从不修改不是它创建的记录。如果 Cloudflare 上已经有该主机名的记录，会报 `conflict: existing record not owned by labelgate`。请在 Cloudflare 上删除那条记录，或换一个主机名。参见[所有权与冲突](/zh/docs/ownership)。

## 标签写错时 [#strict-validation]

Labelgate 会检查每个标签。问题会显示在日志和 Dashboard 中，并带上容器名和标签键。

| 错误 | 结果 |
|------|------|
| 值不合法，如 `proxied: "maybe"` | 跳过该名字。它之前创建的记录保持原样，直到你修正标签。 |
| 未知属性，如 `labelgate.dns.web.proxyed` | 报错，该名字的其他标签照常生效。 |
| 未知类型或段数不够，如 `labelgate.dnss.web.hostname` | 报错，忽略该标签。 |
| `default` 标签不合法 | 跳过该容器里这一类型的所有名字。 |
| 不带前缀的标签 | 直接忽略，不报错。 |

布尔值可以写 `true`/`false`、`yes`/`no`、`on`/`off` 或 `1`/`0`。

## 标签类型

- [DNS 标签](/zh/docs/labels/dns)：DNS 记录。
- [Tunnel 标签](/zh/docs/labels/tunnel)：Cloudflare Tunnel 路由。
- [Access 标签](/zh/docs/labels/access)：在主机名前加一道 Zero Trust Access 登录。
