每张表列出配置文件中的键、对应的环境变量、默认值和作用。设置方式见[配置](/zh/docs/configuration)。

- 时长要带单位：`30s`、`5m`、`24h`。零请写 `0s`。
- 环境变量中的列表用逗号分隔：`a.example.com,b.example.com`。
- 带 `<name>` 或 `<id>` 的键属于映射部分，只能写在配置文件里。

## 基础设置 [#basic-settings]

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `mode` | `LABELGATE_MODE` | `main` | `main`，远程 Docker 主机上用 `agent`。 |
| `log_level` | `LABELGATE_LOG_LEVEL` | `info` | `debug`、`info`、`warn` 或 `error`。 |
| `log_format` | `LABELGATE_LOG_FORMAT` | `text` | `text` 或 `json`。 |
| `label_prefix` | `LABELGATE_LABEL_PREFIX` | `labelgate` | 所有标签键的第一段。可用小写字母、数字、`.`、`_`、`-`。 |
| `default_tunnel` | `LABELGATE_DEFAULT_TUNNEL` | - | 标签没写 `tunnel` 时使用的 tunnel。留空表示 `cloudflare.tunnel_id`，否则填 `cloudflare.tunnels` 中的名字。 |
| `instance_id` | `LABELGATE_INSTANCE_ID` | - | 仅在数据库丢失后恢复时使用。4-32 位小写字母和数字。参见[所有权](/zh/docs/ownership)。 |
| `skip_credential_validation` | `LABELGATE_SKIP_CREDENTIAL_VALIDATION` | `false` | 启动时不校验 Cloudflare token，也不要求必须配置 token。 |
| - | `LABELGATE_CONFIG` | - | 配置文件路径。 |

## Cloudflare [#cloudflare-credentials]

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `cloudflare.api_token` | `LABELGATE_CLOUDFLARE_API_TOKEN` | - | **必填**，除非使用 `cloudflare.credentials`。主 API token。 |
| `cloudflare.account_id` | `LABELGATE_CLOUDFLARE_ACCOUNT_ID` | - | tunnel 所属账户。设置了 `tunnel_id` 时**必填**。 |
| `cloudflare.tunnel_id` | `LABELGATE_CLOUDFLARE_TUNNEL_ID` | - | tunnel 标签使用的默认 tunnel。使用 `cloudflare.api_token` 管理。 |
| `cloudflare.credentials.<name>.api_token` | 仅配置文件 | - | **必填。** 额外的 API token。 |
| `cloudflare.credentials.<name>.zones` | 仅配置文件 | 所有 zone | 该 token 用于哪些 zone，如 `example.com`。 |
| `cloudflare.tunnels.<name>.account_id` | 仅配置文件 | - | **必填。** 额外 tunnel 所属账户。 |
| `cloudflare.tunnels.<name>.tunnel_id` | 仅配置文件 | - | **必填。** 额外 tunnel 的 ID。 |
| `cloudflare.tunnels.<name>.credential` | 仅配置文件 | `cloudflare.api_token` | 用 `credentials` 中的哪个名字管理这个 tunnel。 |

`credentials` 和 `tunnels` 下的名字只能用小写字母、数字、`-` 和 `_`。`default` 是保留名。

tunnel 的连接器 token（`TUNNEL_TOKEN`）不是 Labelgate 的设置，它属于 cloudflared，参见 [cloudflared 配置](/zh/docs/examples/cloudflared)。

### 多个 API token [#multi-credential-setup]

当你的 zone 分属不同 Cloudflare 账户，或需要使用不同 token 时使用。

```yaml
cloudflare:
  api_token: main-token
  credentials:
    company:
      api_token: company-token
      zones: [company.io]
  tunnels:
    secondary:
      account_id: company-account-id
      tunnel_id: company-tunnel-id
      credential: company
```

Labelgate 为主机名选择 token 的方式：

1. 优先使用 `credential` 标签。`credential: default` 表示 `cloudflare.api_token`。
2. 否则选能看到该主机名所在 zone 的 token。有多个时，zone 名最长的胜出；长度相同时 `cloudflare.api_token` 胜出。
3. 没有合适的 token 时，标签会显示错误。

在 `zones` 中，`example.com` 表示这个 zone 本身。`*.example.com` 匹配它下面的 zone（如 `dev.example.com`），但不包括 `example.com`。

`tunnel` 标签必须引用已配置的 tunnel（名字或 ID）。未知的 tunnel 会报错。

## 同步与清理 [#sync]

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `sync.interval` | `LABELGATE_SYNC_INTERVAL` | `5m` | 在 Docker 事件之外，定期与 Cloudflare 完整核对一次。最小 `10s`。 |
| `sync.remove_delay` | `LABELGATE_SYNC_REMOVE_DELAY` | `30m` | 容器消失后等待多久再删除它的资源（`cleanup: true`）。`0s` 表示立即删除。 |
| `sync.orphan_ttl` | `LABELGATE_SYNC_ORPHAN_TTL` | `0s` | 被保留的资源（`cleanup: false`）多久后被遗忘。只删除数据库条目，从不删除 Cloudflare 上的对象。`0s` 表示永不。 |
| `sync.agent_grace` | `LABELGATE_SYNC_AGENT_GRACE` | `24h` | 离线 agent 的资源保留多久。最小 `5m`。 |

Labelgate 只会删除自己创建的资源，参见[所有权与冲突](/zh/docs/ownership)。

## Docker [#docker-provider]

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `docker.endpoint` | `LABELGATE_DOCKER_ENDPOINT` | `unix:///var/run/docker.sock` | Docker daemon 地址：`unix:///path` 或 `tcp://host:port`。 |
| `docker.poll_interval` | `LABELGATE_DOCKER_POLL_INTERVAL` | `2m` | 在 Docker 事件之外，每隔多久重新列出所有容器。必须大于 `0s`。 |
| `docker.filter_label` | `LABELGATE_DOCKER_FILTER_LABEL` | - | 只读取带有该标签的容器：`key` 或 `key=value`。 |
| `docker.tls.ca` | `LABELGATE_DOCKER_TLS_CA` | - | 校验 `tcp://` daemon 证书用的 CA 文件。 |
| `docker.tls.cert` | `LABELGATE_DOCKER_TLS_CERT` | - | 客户端证书。需与 `key` 同时设置。 |
| `docker.tls.key` | `LABELGATE_DOCKER_TLS_KEY` | - | 客户端私钥。 |
| `docker.tls.insecure_skip_verify` | `LABELGATE_DOCKER_TLS_INSECURE_SKIP_VERIFY` | `false` | 不校验 daemon 的证书。仅用于测试。 |

`tcp://` 地址只有在设置了任一 `docker.tls.*` 时才使用 TLS，否则是明文、无认证的连接。

## 数据库 [#database]

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `db.path` | `LABELGATE_DB_PATH` | `/app/config/labelgate.db` | SQLite 文件。把 `/app/config` 放在 volume 上并做好备份。 |

## API 与 Dashboard [#api-server--dashboard]

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `api.enabled` | `LABELGATE_API_ENABLED` | `true` | 提供 API 和 Dashboard。 |
| `api.address` | `LABELGATE_API_ADDRESS` | `:8080` | 监听地址。 |
| `api.base_path` | `LABELGATE_API_BASE_PATH` | `/api` | API 路径。以 `/` 开头，不能以 `/` 结尾，不能是 `/dashboard`。 |
| `api.token` | `LABELGATE_API_TOKEN` | - | 使用 API 和 Dashboard 时**必填**。至少 16 个字符。留空则两者都关闭。 |

用 `openssl rand -hex 32` 生成 token。Dashboard 地址是 `/dashboard/`。不要把端口直接暴露到公网，请放在 VPN、带 TLS 的反向代理或 Cloudflare Access 后面。

### 接口 [#endpoints]

除 `/health` 外，所有接口都需要请求头 `Authorization: Bearer <api.token>`。下面的路径使用默认的 `/api`。

| 接口 | 返回 |
|------|------|
| `GET /api/health` | `{"status":"ok"}`。无需 token。 |
| `GET /api/overview` | 资源数量、同步状态和 agent 概况。 |
| `GET /api/resources/dns` | DNS 记录。 |
| `GET /api/resources/tunnels` | Tunnel 路由。 |
| `GET /api/resources/access` | Access 应用。 |
| `GET /api/agents` | Agent 列表。 |
| `GET /api/version` | 版本信息。 |

资源列表支持 `status`、`agent_id`、`hostname`、`limit`（默认 `500`，最大 `1000`）和 `offset` 参数。

### 健康检查 [#healthcheck]

镜像会运行 `labelgate healthcheck`。它读取同一份配置，所以自定义的 `api.address` 或 `api.base_path` 无需额外设置。

- main，API 开启且设置了 `api.token`：`/health` 在 2 秒内响应即为健康。
- main，API 关闭或没有 `api.token`：始终健康。
- agent：inbound 模式检查 `connect.listen` 能否连接；outbound 模式始终健康。

## 重试 [#retry-settings]

用于 Cloudflare 调用和 agent 重连。

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `retry.attempts` | `LABELGATE_RETRY_ATTEMPTS` | `3` | 最多尝试次数。至少 `1`。 |
| `retry.delay` | `LABELGATE_RETRY_DELAY` | `1s` | 第一次重试前的等待时间。必须大于 `0s`。 |
| `retry.max_delay` | `LABELGATE_RETRY_MAX_DELAY` | `30s` | 最长等待时间。不小于 `retry.delay`。 |
| `retry.backoff` | `LABELGATE_RETRY_BACKOFF` | `2` | 每次重试后等待时间乘以该倍数。至少 `1`。 |

## Agent：main 实例 [#agent-server-main-instance]

main 实例上用于接入 [agent](/zh/docs/examples/multi-host) 的设置。

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `agent.enabled` | `LABELGATE_AGENT_ENABLED` | `false` | 接受 agent 连接。 |
| `agent.listen` | `LABELGATE_AGENT_LISTEN` | `:8081` | 监听地址。agent 连接 `wss://<host>:8081/ws`。 |
| `agent.accept_token` | `LABELGATE_AGENT_ACCEPT_TOKEN` | - | 给未列在 `agent.agents` 中的 agent 使用的共享 token。参见 [Agent token](#agent-tokens)。 |
| `agent.accept_hostnames` | `LABELGATE_AGENT_ACCEPT_HOSTNAMES` | 任意 | 这些 agent 可用的主机名，支持通配：`*.edge.example.com`。通配符主机名需要完全相同的条目。 |
| `agent.accept_tunnels` | `LABELGATE_AGENT_ACCEPT_TUNNELS` | 默认 tunnel | 这些 agent 可用的 tunnel：`default`、`cloudflare.tunnels` 中的名字或 tunnel ID。 |
| `agent.accept_services` | `LABELGATE_AGENT_ACCEPT_SERVICES` | IP 地址 | 这些 agent 在 tunnel `service` 中额外可用的主机：主机名通配、IP 或 CIDR。 |
| `agent.tls.cert` | `LABELGATE_AGENT_TLS_CERT` | - | 服务端证书，用于开启 `wss://`。需与 `key` 同时设置。 |
| `agent.tls.key` | `LABELGATE_AGENT_TLS_KEY` | - | 服务端私钥。 |
| `agent.tls.ca` | `LABELGATE_AGENT_TLS_CA` | 系统 CA | 校验 inbound agent 证书用的 CA。 |
| `agent.tls.insecure_skip_verify` | `LABELGATE_AGENT_TLS_INSECURE_SKIP_VERIFY` | `false` | 不校验 inbound agent 的证书。仅用于测试。 |

### 单个 agent 条目 [#per-agent-entries]

`agent.agents.<id>` 只能写在配置文件里。`<id>` 是 agent ID：小写字母、数字、`.`、`_` 和 `-`，最长 63 个字符，必须与 agent 的 `connect.agent_id` 一致。带点的 ID 要写成一个键：YAML 写 `nas.lan:`，TOML 写 `[agent.agents."nas.lan"]`。

| 键 | 默认值 | 作用 |
|----|--------|------|
| `token` | - | **必填。** 该 agent 的 token。参见 [Agent token](#agent-tokens)。 |
| `name` | - | 在 Dashboard 中显示的名称。 |
| `default_tunnel` | `default_tunnel` | 该 agent 的标签没写 `tunnel` 时使用的 tunnel。 |
| `tunnels` | 它的默认 tunnel | 该 agent 可用的 tunnel。 |
| `hostnames` | 任意 | 该 agent 可用的主机名，支持通配。通配符主机名需要完全相同的条目。 |
| `services` | IP 地址 | 该 agent 在 tunnel `service` 中额外可用的主机：主机名通配、IP 或 CIDR。 |
| `connect_to` | - | 以 `/ws` 结尾的 `ws://` 或 `wss://` 地址。由 main 主动连接 agent（inbound 模式）。 |

```yaml
agent:
  enabled: true
  agents:
    edge1:
      token: "<openssl rand -hex 32>"
      hostnames: ["*.edge1.example.com"]
      services: ["web", "172.20.0.0/16"]
```

### Agent token [#agent-tokens]

`agent.agents.<id>.token`、`agent.accept_token` 和 `connect.token` 至少要有 32 个字符，且至少包含 12 个不同的字符，否则 Labelgate 无法启动。用下面的命令生成：

```bash
openssl rand -hex 32
```

## Agent：agent 实例 [#agent-connection-agent-instance]

只在 `mode: agent` 下使用。agent 模式下只使用这些设置以及 `log_*`、`docker` 和 `retry`。

| 键 | 环境变量 | 默认值 | 作用 |
|----|----------|--------|------|
| `connect.mode` | `LABELGATE_CONNECT_MODE` | `outbound` | `outbound`：agent 连接 main。`inbound`：main 连接 agent。 |
| `connect.endpoint` | `LABELGATE_CONNECT_ENDPOINT` | - | outbound 时**必填**。main 的地址，要带 `/ws`：`wss://main.example.com:8081/ws`。 |
| `connect.listen` | `LABELGATE_CONNECT_LISTEN` | - | inbound 时**必填**。监听地址，如 `:8082`。 |
| `connect.token` | `LABELGATE_CONNECT_TOKEN` | - | **必填。** 与 main 上的 token 相同。参见 [Agent token](#agent-tokens)。 |
| `connect.agent_id` | `LABELGATE_CONNECT_AGENT_ID` | 由机器 ID 生成 | Agent ID。默认取自 `/etc/machine-id`，否则用主机名。请设置成与 main 上一致。 |
| `connect.heartbeat_interval` | `LABELGATE_CONNECT_HEARTBEAT_INTERVAL` | `30s` | agent 多久发送一次完整上报。最小 `1s`。 |
| `connect.tls.ca` | `LABELGATE_CONNECT_TLS_CA` | 系统 CA | 校验 main 证书用的 CA。 |
| `connect.tls.cert` | `LABELGATE_CONNECT_TLS_CERT` | - | 仅 inbound：服务端证书。需与 `key` 同时设置。 |
| `connect.tls.key` | `LABELGATE_CONNECT_TLS_KEY` | - | 仅 inbound：服务端私钥。 |
| `connect.tls.insecure_skip_verify` | `LABELGATE_CONNECT_TLS_INSECURE_SKIP_VERIFY` | `false` | 不校验 main 的证书。仅用于测试。 |

## 已移除的配置项 [#removed-keys]

下列 v0.2 配置项现在会导致无法启动，请从配置文件和环境变量中删除：

- `docker.ssh.host`（`LABELGATE_DOCKER_SSH_HOST`）
- `docker.ssh.key`（`LABELGATE_DOCKER_SSH_KEY`）
- `docker.ssh.key_passphrase`（`LABELGATE_DOCKER_SSH_KEY_PASSPHRASE`）
- `docker.ssh.known_hosts`（`LABELGATE_DOCKER_SSH_KNOWN_HOSTS`）
- `db.retention`（`LABELGATE_DB_RETENTION`）
- `db.vacuum_interval`（`LABELGATE_DB_VACUUM_INTERVAL`）

`docker.endpoint` 中的 `ssh://` 地址同样会被拒绝。要管理远程 Docker 主机，请在那里运行一个 Labelgate [agent](/zh/docs/examples/multi-host)，或使用 `tcp://` 加 `docker.tls.*`。
